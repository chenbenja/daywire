# Research notes — round 51 (5 Nov 2026)

Zero-install / low-friction delivery options.

## OpenClaw install

[docs.openclaw.ai/install](https://docs.openclaw.ai/install): `curl install.sh | bash`, installs Node, onboarding; macOS / Linux / Windows; Telegram bot token, WhatsApp QR; iMessage needs Mac + `imsg` + Full Disk Access; VPS or Mac mini recommended (macos-vm docs).

## Android developer verification

[developer.android.com/developer-verification](https://developer.android.com/developer-verification) + Android Developers Blog Jun 2026: enforced 30 Sep 2026 in Brazil, Indonesia, Singapore, Thailand for participating stores; global 2027; advanced flow (Developer options, restart, 24 h wait); ADB exempt.

## Home Assistant Companion sensors

Last notification / removed / active count via NotificationListenerService, allow list, 15-minute worker ([companion docs](https://companion.home-assistant.io/docs/core/sensors/)); grouped-notification issue [#4585](https://github.com/home-assistant/android/issues/4585).

## WhatsApp

Business API bars general-purpose AI providers from 15 Jan 2026 (TechCrunch); unofficial clients violate ToS and risk bans (WhatsApp FAQ).
