syscall_musl.go.overlay is a modified copy of syscall_musl.go from
modernc.org/libc v1.79.0 (https://gitlab.com/cznic/libc).

The file header in that release says Copyright 2024 The Libc Authors.
The module LICENSE file says Copyright 2017 The Libc Authors.
Both are reproduced here. This repository does not add a project LICENSE
file. The overlay is used only while binding the Android archive. It
rewrites a few x86_64 syscalls so Android's app seccomp filter does not
kill the store thread on an emulator.
